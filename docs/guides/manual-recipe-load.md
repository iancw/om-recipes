# How to load recipes into the camera manually

Dialing in a profile is fairly straightforward once you know where to look.

## Manually entering a color profile

1. Turn the Creative Dial to COLOR.
2. Choose a Color Profile: 1, 2, 3, or 4.
    * This is a memory slot where your recipe settings are saved.
    * You get four color profiles per Mode Dial setting (C1–C5 and B/M/S/A/P).
    * All four share the same custom white balance, which is tied to the Mode Dial setting.
    * You can't switch color profile slots with a dial or button. Bring up the super control panel (OK button), navigate to the Color Profile slot, and use the front or rear dial to switch.
3. Color Vivid
    * This screen is where you change the per-color saturation values.
    * Turn the front dial to move around the color wheel — first "all colors" together, then each of the 12 individual channels. Use the rear dial to set the saturation from -5 to +5.
    * Setting saturation per color across all 12 colors is the headline feature of the "Creative Dial" cameras (Pen-F, E-P7, OM-3).
4. Tone curve
    * Front dial controls highlights.
    * Rear dial controls shadows.
    * The Info button switches between the midtone control and the shadow/highlight controls.
5. Shading effect (vignette)
    * Negative values add a dark vignette, darker the further down you go. Positive values add a white vignette.
6. Sharpness
    * Adjust from -2 to +2.
    * Less sharpness can be flattering for portraits or for an older look.
7. Contrast
    * Adjust global contrast from -2 to +2.
    * Similar to raising highlights and lowering shadows on the tone curve.

The 12 color-channel saturation settings are the fiddly part. This site lays them out to match the camera's screen so it's easier to follow along.
