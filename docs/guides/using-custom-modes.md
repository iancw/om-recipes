# Using Custom Dial Modes for Recipes

Lots of recipes rely on white balance shifts, and the hardware makes it awkward to switch between color profiles, so many recipe enthusiasts use custom modes to store their recipes.

Each of the 5 custom modes on the OM-3 gets its own set of 4 Color Profiles. The B/M/S/A/P modes all share one set of four Color Profile slots, so if you set Color Profile 1 in M mode and then switch to S or A, you'll see the same settings. Switch to a C1–C5 custom mode, though, and the profiles are separate. White balance works the same way: shared across B/M/S/A/P, separate for each of C1–C5.

White balance and WB offsets aren't tied to a Color Profile slot, only to the main dial mode. All four Color Profiles in a mode share the same white balance.

When you use custom modes C1–C5, it helps to know they can behave two ways on power-off or mode switch: **Save Settings: Reset** or **Save Settings: Hold**. With Hold, any change you make (like editing a color profile) is saved automatically when you power off or switch modes. With Reset, your changes are thrown away unless you go into the custom mode menu and run **Assign: Set**.

Reset is handy when everything's configured and you want to be sure you don't accidentally change something important, or forget to set it back afterward. It's frustrating, though, when you're trying to enter a color profile and expect it to stick.

## Keeping track of recipe settings across custom modes

One great addition on the OM-3 is being able to name the custom modes (C1–C5). Individual color profiles still can't be named, so it's easy to lose track of which color profile you saved into which slot on which custom mode.

One approach that helps: use Color Profile slots 1–4 for consistent themes. I like to stick with roughly these defaults:

1. Profile 1 — the normal, everyday recipe ("normal")
2. Profile 2 — a bit more contrast and saturation ("a little punch")
3. Profile 3 — heavy on contrast and saturation ("bold and punchy")
4. Profile 4 — less contrast, less saturation ("light and airy")

Another option is the [Camera Settings](https://om-recipes.com/camera-settings) page, which lets you record which color profiles are loaded into which slots in which modes. It can also filter for recipes with compatible white balance. It's only as accurate as you keep it, but it can be handy.

You could also jot them down in your camera notebook, or print a cheat sheet and tape it to the bottom of your camera (or behind the screen).
