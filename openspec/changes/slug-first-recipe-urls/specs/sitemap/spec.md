## MODIFIED Requirements

### Requirement: Sitemap lists all public recipe URLs
The app SHALL expose a `/sitemap.xml` generated by `app/sitemap.js` that includes one entry per public recipe, using the recipe's slug as the canonical URL path segment.

#### Scenario: Sitemap includes recipe URLs
- **WHEN** a crawler fetches `/sitemap.xml`
- **THEN** the response contains one `<url>` entry per recipe, each with a `<loc>` of the form `https://<domain>/recipes/<slug>`

#### Scenario: Sitemap uses slug as the canonical path
- **WHEN** a recipe has both a UUID and a slug
- **THEN** the sitemap entry uses the slug rather than the UUID

#### Scenario: Sitemap returns valid XML
- **WHEN** `/sitemap.xml` is fetched
- **THEN** the response has `Content-Type: application/xml` and conforms to the sitemap protocol schema
